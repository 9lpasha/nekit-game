# 🛶 Двое в лодке, не считая зомби

Кооперативная браузерная игра на двоих: каждый играет со своего телефона. Вы плывёте к Острову, а заражённые на плотах швыряют в лодку камни, слизь и бочки. Отбивайте всё ракетками для настольного тенниса.

🎮 **Играть:** https://9lpasha.github.io/nekit-game/

Собрано на чистом HTML + JavaScript, без сборки и без своего сервера. Подходит для GitHub Pages.

## Как играть

- **Левый палец** (левая половина экрана): джойстик, бегать по лодке.
- **Правый палец** (правая половина): удар ракеткой.
  - **свайп** — удар в сторону свайпа (с автоприцелом по врагам и напарнику);
  - **тап** — автоудар по ближайшему снаряду.
- Красный крестик на палубе показывает, куда упадёт снаряд. Подбегите и отбейте.
- **Розыгрыш:** отбейте мяч в сторону напарника, и он полетит к нему, заряжаясь (🔵 → 🟢 → 🟡 → 🟠). Пятое касание даёт **СМЭШ** со взрывом по площади. Если напарник не отобьёт, мяч упадёт и повредит лодку.
- Удар точно в момент подлёта даёт «ИДЕАЛЬНО!»: двойной урон и больше очков.
- **Пробоины:** неотбитый снаряд пробивает дно, и через дыру течёт вода. Лодка тонет при 100% воды.
- **Заплатки:** встаньте на пробоину, и через секунду она залатана (тратится 1 доска).
- **Доски** плывут вдоль бортов (в жёлтом кольце). Ударьте по доске ракеткой, и она окажется на борту. Иногда доски роняют разбитые плоты зомби.
- **Ведро** на корме: пока стоите рядом, вода убывает. По колено в воде бегать медленнее.
- **Штурвал** у носа: встаньте к нему, джойстик влево-вправо рулит лодкой, вниз — отойти. Уводите лодку от **скал** (удар пробивает дно) и **водоворотов** (тормозят и затягивают).
- **Шторм** догоняет сзади: чем больше воды в лодке, тем она медленнее. В шторме вода прибывает сама, а молнии пробивают палубу.
- **Карты** (полоска внизу экрана, на компьютере — клавиши 1–4). Эликсир и колода общие на двоих — договаривайтесь, кто что тратит:
  🗼 Башенка (сама стреляет по зомби), 🛡️ Щит (купол над лодкой), 💣 Бомба (взрыв по толпе), ❄️ Заморозка, 🔧 Ремонт (латает дыры без досок), 🐦 Чайка (приносит доски).
- **Сундук** после каждой волны: игра на паузе, выберите одну из трёх наград — новую карту, улучшение карты (до ★3), доски или полный эликсир. Выбирает любой из двоих.
- **Боссы:** на трети пути — 🐍 Морской змей (ныряет, плюётся, бьёт хвостом), на двух третях — ⛰️ Каменный великан (валуны, каменный дождь, топот). Красные клетки на палубе — туда вот-вот прилетит удар. Пока идёт бой, лодка стоит.
- **Нитро «Мы — семья»:** баллоны плывут вдоль бортов (синие, ловятся ракеткой), ещё дают за боссов. Нитро срабатывает, только если **оба** нажмут кнопку N₂O почти одновременно (на компьютере — клавиша N). Лодка мчит быстрее и проламывает скалы носом.
- **Финальная погоня:** у самого острова впереди появляется катер рейдеров, шторм ускоряется. Потопите катер — большой бонус.
- **Ракушки 🐚** за каждый заплыв (очки, боссы, рейдеры, победа). В **магазине** — постоянные улучшения (доски и эликсир на старте, крепкое дно, нитро, заморозка в колоде) и раскраски ракетки. Вдвоём действует лучшее улучшение из двух. Прогресс хранится на телефоне.
- **Кат-сцены:** вступление (лодка, море и остров вдали), появление каждого босса и рейдеров, финал на острове — лагерь, костёр, проектор и кино на походных стульях. Пропустить — **удерживать** кнопку ⏩ в правом верхнем углу (на компьютере — Esc); пропуск срабатывает у обоих игроков.
- **Цель** — доплыть до острова (~5 минут). Полоса под уровнем воды показывает путь: белая метка — лодка, фиолетовая — шторм.

На компьютере: WASD/стрелки — бег, клик — удар в сторону курсора, пробел — автоудар.

## Как играть вдвоём

1. Оба открывают ссылку на игру.
2. Первый жмёт **«Создать комнату»** и получает 4-буквенный код (или кнопку «Отправить ссылку»).
3. Второй вводит код и жмёт **«Войти»**.

Нужен интернет, но только чтобы найти друг друга. Игроки находят друг друга через публичные Nostr-реле (библиотека [Trystero](https://github.com/dmotz/trystero)), а дальше телефоны общаются напрямую по WebRTC. Если оба в одной Wi-Fi сети, трафик идёт локально.

> В некоторых мобильных сетях (строгий NAT) прямое соединение не устанавливается. Тогда подключите оба телефона к одному Wi-Fi или раздайте интернет с одного телефона на другой.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `nekit-game`) и загрузите туда все файлы из этой папки.
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
3. Через минуту игра будет доступна по адресу `https://<ваш-логин>.github.io/nekit-game/`.

## Запуск локально

Нужен статический сервер (модули ES не работают через `file://`). В проекте есть `serve.py` — он запрещает браузеру кэш, чтобы после правок не смешивались старые и новые файлы:

```bash
python serve.py
```

- `http://localhost:8123/` — сама игра;
- `http://localhost:8123/dev.html` — два «телефона» рядом в одном окне, связь между вкладками без интернета (для отладки);
- `http://localhost:8123/dev.html?net=p2p` — то же, но через настоящий WebRTC;
- `?island=60` (к любому адресу) — короткий путь до острова, чтобы быстро проверить финал.

С телефона в той же Wi-Fi сети: `python serve.py 8123 0.0.0.0` и открыть `http://<IP-компьютера>:8123/`.

## Устройство кода

| Файл | Что внутри |
|---|---|
| `src/const.js` | размеры мира и лодки, общие константы |
| `src/sim.js` | игровая логика: волны, враги, снаряды, удары, розыгрыш, смэш, пробоины и вода |
| `src/voyage.js` | плавание: штурвал, скалы, водовороты, шторм, остров |
| `src/cards.js` | карты, эликсир, башенки, сундуки |
| `src/boss.js` | боссы и финальная погоня за рейдерами |
| `src/progress.js` | ракушки, магазин, раскраски (localStorage) |
| `src/cutscene.js` | кат-сцены: вступление, боссы, финал на острове |
| `src/net.js` | сеть: Trystero (WebRTC) или BroadcastChannel для отладки |
| `src/main.js` | меню, комнаты, роли хост/гость, главный цикл |
| `src/render.js` | отрисовка на Canvas: море, лодка, персонажи, эффекты, HUD |
| `src/input.js` | джойстик, свайпы, клавиатура и мышь |
| `src/sfx.js` | 8-битные звуки на WebAudio |

**Сетевая модель:** игру считает телефон того, кто создал комнату (хост), и 30 раз в секунду отправляет гостю снимок состояния. Гость двигает своего персонажа сам (без задержки) и отправляет хосту свою позицию и удары.
